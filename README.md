- `script.js` — mobile navigation
- `assets/profile.jpg` — profile photo

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, for example `shahaji-portfolio`.
2. Upload **all files and the `assets` folder** from this project.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your live website URL.

Your website URL will normally look like:
`https://shahaji041.github.io/shahaji-portfolio/`

You can then add that URL to your LinkedIn profile under **Contact info**, **Featured**, or your profile's website section.
